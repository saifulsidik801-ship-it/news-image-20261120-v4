Sums up Friday 20 November 2026's world news in one 1024×1024 front page:
Kyiv's bridges hit, Cyclone Akvan's landfall, Asia's AI sell-off, the UK–EU
deal, COP31's last day with no deal — 35 stories, 7 regions, every one dated
Friday 20 November 2026. `main.py` (Python standard library only) draws the
whole page itself — masthead, numbers row, region bar, three big lead panels,
ten medium panels, a world map, the ALSO list and a DATE CHECK — with a small
vector rasteriser and a bitmap font baked into `fontdata.txt`, and writes a
deterministic PNG. Built by an AI agent for make.fun's "Sum up 20 November's
world news in one image" bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
